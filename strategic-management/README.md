# Strategic Management

A structured guide to strategic management — from foundational concepts through
corporate strategy, global expansion, and execution. Each topic covers the core
concept, key terms, real use cases, and worked examples, followed by 210 practice
questions graded Basic → Intermediate → Advanced across two modules.

---

## Module I — Competitive Strategy

| Topic | What You Will Learn |
|-------|---------------------|
| SM Foundations | Strategy basics, vision/mission, competitive advantage |
| External Environment | PEST/PESTEL analysis and scenario planning |
| Industry Analysis | Porter's Five Forces and practical application |
| Internal Analysis | RBV, value chain, and competitor analysis |
| Business-Level Strategy | Cost leadership, differentiation, Blue Ocean, platform |
| Corporate & Global Strategy | Organic/inorganic growth, internationalization, entry modes |

## Module II — Corporate Strategy
