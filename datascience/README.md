# Data Science Interview Preparation

A 30-session Q&A series by **iNeuron.AI** covering the full spectrum of Data Science
and Machine Learning interview topics — from core algorithms and NLP through advanced
deep learning architectures and computer vision research papers.

---

## ML & AI Foundations

| Topic | Key Concepts |
|-------|-------------|
| AI, ML, DL & Data Science | Definitions and differences across AI disciplines |
| Logistic Regression | Binary classification, sigmoid, log-loss |
| Regression & Heteroscedasticity | OLS assumptions, residuals, error distribution |
| Imbalanced Data & Sampling | Upsampling, downsampling, class imbalance |
| Neural Network Training & Epochs | Batches, epochs, underfitting, training loops |
| NLP Fundamentals & Libraries | NLTK, SpaCy, Gensim, TextBlob, CoreNLP |
| Time Series & Stationarity | Differencing, AR processes, transformations |
| TensorFlow & DL Frameworks | TensorFlow, Keras, model building |
| Machine Learning Fundamentals | Supervised learning, patterns from data |
| Recommender Systems | Collaborative filtering, content-based filtering |
