# Space Invaders Instructions

This compatibility page replaces an upstream SPD project instruction link.

## Practical Goal

Use the project to apply decomposition, state transitions, event handling, and incremental design.

## Suggested Workflow

1. Define the data model for game state first.
2. Keep rendering separate from update logic.
3. Add one mechanic at a time: player movement, firing, enemies, collisions, score.
4. Write tests for state transitions before polishing visuals.
