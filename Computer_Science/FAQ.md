# FAQ

## What is this folder?

`Computer_Science` is a self-contained copy of the local `CSE` curriculum integrated into the `system_design`
app.

## Why are there compatibility pages here?

Some copied markdown files originally linked to upstream OSSU repository documents that were not present in the local
`CSE`
folder. These compatibility files keep navigation working without depending on external local folders.

## Where should I start?

Start with [README.md](README.md), then move through Foundation, Core CS, Advanced, and Projects in order.

## Are the original upstream materials still relevant?

Yes. Many copied notes were derived from OSSU and other public sources. This local folder is an integrated study surface, not a replacement for those public projects.

## Why require experience with a sizable project before software engineering material?

Because architecture and engineering tradeoffs are easier to understand after you have built and debugged non-trivial systems. The local project paths in
`04_Projects` are the intended bridge.
