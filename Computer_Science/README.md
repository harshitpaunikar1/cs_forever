# Computer Science Study Guide

This study guide is organized as a practical computer science curriculum rather than a loose collection of notes. The goal is to move from programming fluency into systems understanding, then into advanced infrastructure, security, distributed systems, and substantial projects.

The material is intentionally layered. Foundation builds programming comfort and mental models. Core CS explains how real software behaves under the hood. Advanced topics show how those ideas scale into production systems, research systems, and performance-sensitive tooling. Projects convert the reading path into portfolio-quality work.

## How to Use This Guide

1. Start with `Foundation` unless you already write code comfortably and can explain stack vs heap, the shell, and Git basics.
2. Move through `Core CS` in order. The sections were arranged so that algorithms, architecture, operating systems, databases, networking, and backend design reinforce each other.
3. Treat `Advanced` as specialization material. You do not need every topic immediately, but the sequence is designed for serious systems work.
4. Use `Projects` as the proof layer. If you cannot build something from a topic, you do not fully own it yet.
5. Use `Resources` for primary references, PDFs, and extracted source notes when you want deeper detail.

## Section Map

- `Foundation`: learning roadmap, programming basics, workflow, C, Python, Rust, and computer organization.
- `Core CS`: data structures, architecture, operating systems, databases, networking, HTTP/TLS, and backend systems.
- `Advanced`: distributed systems, security, containers, Kubernetes, observability, AI infrastructure, kernel reading, profiling, and media systems.
- `Projects`: beginner, intermediate, and advanced paths.
- `Resources`: image, PDF, and source-note indexes.
