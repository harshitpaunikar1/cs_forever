# Contributing

This `Computer_Science` section is a self-contained integration of local curriculum material into the `system_design`
app.

## What This File Is

This document is a compatibility page for copied references that originally pointed to upstream OSSU repository files.

## Local Editing Rules

1. Keep all runtime content inside
`system_design/Computer_Science`.
2. Do not introduce dependencies on `../CSE` or `../CSE_Repository`.
3. Preserve the existing app flow: `nav.json`
drives navigation and markdown files are loaded directly.

## Improvements

- Fix broken local links or missing assets inside
`Computer_Science`.
- Expand compatibility notes when a copied page expects missing upstream context.
- Add new material only if it remains self-contained inside this folder.

## Upstream Reference

The original OSSU contribution workflow lives in the public OSSU repository:
<https://github.com/ossu/computer-science>
