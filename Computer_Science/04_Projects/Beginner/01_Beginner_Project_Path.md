# Beginner Project Path

## Overview

These projects are designed to convert early programming knowledge into working software with clear inputs, outputs, and testable behavior. The emphasis is on finishing cleanly, not showing off complexity.

## Learning Goals

- build confidence with file and data handling
- structure small programs into functions and modules
- document behavior clearly
- practice testing and debugging discipline

## Projects

### Project 1: Command-Line File Organizer
Build a tool that sorts files into folders by extension, date, or naming pattern.

Deliverables:
- dry-run mode
- undo or preview capability
- log of moved files

### Project 2: Text-Based Adventure Game
Use conditionals, functions, and state management to build a branching terminal game.

Deliverables:
- save and load support
- clear room or scenario structure
- test coverage for core state transitions

### Project 3: Student Grade Tracker
Store records, compute averages, and generate summaries.

Deliverables:
- persistent storage in CSV or JSON
- basic validation
- reporting output

### Project 4: Web Scraper and Data Extractor
Fetch structured data from a public site or API responsibly.

Deliverables:
- clear parsing logic
- retry and error handling
- export to CSV or JSON

### Project 5: Unit Converter CLI
Build a polished command-line tool with multiple conversion families.

Deliverables:
- argument parsing
- helpful usage output
- tests for conversion logic

### Project 6: Contact Book with File Storage
Support create, read, update, delete, and search operations.

Deliverables:
- persistent local storage
- duplicate handling
- import/export support

### Project 7: Log File Analyzer
Parse application logs and summarize errors, frequencies, and time windows.

Deliverables:
- filtering options
- summary report
- support for large input files

### Project 8: Simple HTTP Server
Serve static files or basic dynamic responses.

Deliverables:
- request logging
- status codes
- graceful handling of missing routes

## Completion Standard

Pick any `2-3` projects and finish them to a clean standard rather than starting all eight.
