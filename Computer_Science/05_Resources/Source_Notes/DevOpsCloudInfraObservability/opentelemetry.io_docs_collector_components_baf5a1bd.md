OpenTelemetry Collector components - receivers, processors, exporters, connectors, and extensions

The OpenTelemetry Collector is made up of components that handle telemetry data. Each component has a specific role in the data pipeline.

- Collect telemetry data from various sources and formats[Receivers](https://opentelemetry.io/receiver/)- Transform, filter, and enrich telemetry data[Processors](https://opentelemetry.io/processor/)- Send telemetry data to observability backends[Exporters](https://opentelemetry.io/exporter/)- Connect two pipelines, acting as both exporter and receiver[Connectors](https://opentelemetry.io/connector/)- Provide additional capabilities like health checks[Extensions](https://opentelemetry.io/extension/)
