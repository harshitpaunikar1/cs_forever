# Extra Courses

This local page replaces upstream `extras/courses.md`
references.

Use it as a parking area for worthwhile material that is adjacent to the main roadmap but not required to keep the local progression coherent.

## Good Uses

- language-specific deep dives after Foundation
- specialized systems electives after Core CS
- advanced distributed systems or security courses after the main Advanced path

The required local curriculum remains the content exposed through
`nav.json`.
