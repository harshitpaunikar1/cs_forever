# Modern Programming Languages & Frameworks

Interview question bank from `LLM_Azure_AI_Interview_700_QA.docx`.

## Questions

### 1. What makes a programming language modern?

**Answer:** Strong libraries, safety features, package management, community support, and good tooling.

### 2. Why is Python popular?

**Answer:** It is simple, readable, and has strong libraries for AI, data, automation, and APIs.

### 3. What is Java used for?

**Answer:** Enterprise applications, Android, backend services, banking systems, and large-scaleplatforms.

### 4. What is JavaScript used for?

**Answer:** Web frontend, backend with Node.js,scripting, and full-stack applications.

### 5. What is TypeScript?

**Answer:** TypeScript is JavaScript with static typing to catch errors earlier.

### 6. What is C# used for?

**Answer:** Enterprise apps, APIs, desktop apps, game development, and Microsoft ecosystem development.

### 7. What is Go used for?

**Answer:** Cloud services, APIs, networking tools,and high-performance backend systems.

### 8. What is Rust used for?

**Answer:** Systems programming where memorysafety and performance are important.

### 9. What is framework?

**Answer:** A framework provides structure and reusable components for building applications.

### 10. Library vs framework?

**Answer:** You call a library; a framework often controls the application flow and calls your code.

### 11. What is API?

**Answer:** An API lets one software systemcommunicate with another.

### 12. What is REST API?

**Answer:** A REST API uses HTTP methods like GET, POST, PUT, DELETE to work with resources.

### 13. What is HTTP GET?

**Answer:** GET retrieves data.

### 14. What is HTTP POST?

**Answer:** POST creates or submits data.

### 15. What is HTTP PUT?

**Answer:** PUT updates or replaces a resource.

### 16. What is HTTP PATCH?

**Answer:** PATCH partially updates a resource.

### 17. What is HTTP DELETE?

**Answer:** DELETE removes a resource.

### 18. What is status code 200?

**Answer:** Successful request.

### 19. What is status code 201?

**Answer:** Resource created successfully.

### 20. What is status code 400?

**Answer:** Bad request from client.

### 21. What is status code 401?

**Answer:** Unauthenticated request.

### 22. What is status code 403?

**Answer:** Authenticated but not authorized.

### 23. What is status code 404?

**Answer:** Resource not found.

### 24. What is status code 500?

**Answer:** Server-side error.

### 25. What is JSON?

**Answer:** A lightweight text format for exchanging structured data.

### 26. What is serialization?

**Answer:** Converting data objects into formats likeJSON.

### 27. What is deserialization?

**Answer:** Converting JSON or other formats back into objects.

### 28. What is object-oriented programming?

**Answer:** A programming style based on classesand objects.

### 29. What is class?

**Answer:** A blueprint for creating objects.

### 30. What is object?

**Answer:** An instance of a class with data and behavior.

### 31. What is inheritance?

**Answer:** A class reuses or extends another class's features.

### 32. What is polymorphism?

**Answer:** Different objects can respond to the samemethod call in different ways.

### 33. What is encapsulation?

**Answer:** Keeping data and methods together while hiding internal details.

### 34. What is abstraction?

**Answer:** Showing important features while hiding complex implementation details.

### 35. What is functional programming?

**Answer:** A style based on functions, immutability, and avoiding side effects.

### 36. What is variable scope?

**Answer:** The region where a variable can beaccessed.

### 37. What is exception handling?

**Answer:** Handling runtime errors using try/catch or similar mechanisms.

### 38. What is package manager?

**Answer:** A tool that installs and manages dependencies.

### 39. What is npm?

**Answer:** The package manager commonly used for JavaScript/Node.js.

### 40. What is pip?

**Answer:** The package installer for Python.

### 41. What is Maven?

**Answer:** A Java build and dependency management tool.

### 42. What is Gradle?

**Answer:** A flexible build automation tool used oftenwith Java/Kotlin.

### 43. What is dependency?

**Answer:** External code/library needed by an application.

### 44. What is dependency version conflict?

**Answer:** Two packages need incompatible versionsof another package.

### 45. What is virtual environment?

**Answer:** An isolated environment for project-specific dependencies.

### 46. What is frontend?

**Answer:** The part of an application users see andinteract with.

### 47. What is backend?

**Answer:** The server-side logic, APIs, database access, and business rules.

### 48. What is full-stack development?

**Answer:** Working on both frontend and backend parts.

### 49. What is React?

**Answer:** A JavaScript library for building userinterfaces using components.

### 50. What is component in React?

**Answer:** A reusable UI building block.

### 51. What is state in React?

**Answer:** Data that changes and affects what the UI displays.

### 52. What is props in React?

**Answer:** Data passed from parent component tochild component.

### 53. What is Node.js?

**Answer:** A runtime that allows JavaScript to run on the server.

### 54. What is Express.js?

**Answer:** A lightweight Node.js framework for building APIs.

### 55. What is FastAPI?

**Answer:** A Python framework for building APIs withtype validation and automatic docs.

### 56. What is Django?

**Answer:** A Python web framework with built-in ORM, admin, auth, and project structure.

### 57. FastAPI vs Django?

**Answer:** FastAPI is API-focused and lightweight; Django is full-featured for larger web apps.

### 58. What is Spring Boot?

**Answer:** A Java framework for quickly buildingproduction-ready backend services.

### 59. What is .NET?

**Answer:** .NET is Microsoft's platform for building web, desktop, cloud, and enterprise apps.

### 60. What is microservice?

**Answer:** A small independent service focused onone business capability.

### 61. Microservices vs monolith?

**Answer:** A monolith is one large app; microservices split features into independent services.

### 62. What is database?

**Answer:** A system for storing and retrieving data.

### 63. What is SQL?

**Answer:** A language used to query relational databases.

### 64. What is NoSQL?

**Answer:** Databases that store data in non-relationalformats like documents, key-value, or graphs.

### 65. SQL vs NoSQL?

**Answer:** SQL is structured and relational; NoSQL is flexible and often used for scale or varieddata.

### 66. What is ORM?

**Answer:** Object-Relational Mapper maps database tables to programming objects.

### 67. What is indexing in database?

**Answer:** An index speeds up data lookup.

### 68. What is transaction?

**Answer:** A group of database operations that succeed or fail together.

### 69. What is ACID?

**Answer:** Atomicity, Consistency, Isolation, Durability: properties of reliable transactions.

### 70. What is cache?

**Answer:** A fast storage layer for frequently used data.

### 71. What is Redis?

**Answer:** An in-memory data store often used for caching and queues.

### 72. What is message queue?

**Answer:** A system for sending tasks/messagesbetween services asynchronously.

### 73. What is authentication?

**Answer:** Verifying who the user is.

### 74. What is authorization?

**Answer:** Checking what the user is allowed to do.

### 75. What is JWT?

**Answer:** A signed token often used to represent user identity or claims.

### 76. What is OAuth?

**Answer:** A standard for delegated access, often used for login and API authorization.

### 77. What is CORS?

**Answer:** A browser security rule controllingcross-origin web requests.

### 78. What is middleware?

**Answer:** Code that runs between request and response, often for auth, logging, or validation.

### 79. What is MVC?

**Answer:** Model-View-Controller separates data, UI, and control logic.

### 80. What is design pattern?

**Answer:** A reusable solution to a common softwaredesign problem.

### 81. What is Singleton pattern?

**Answer:** A pattern ensuring only one instance of a class exists.

### 82. What is Factory pattern?

**Answer:** A pattern that creates objects without exposing creation logic.

### 83. What is Repository pattern?

**Answer:** A pattern that abstracts data access logic.

### 84. What is dependency injection?

**Answer:** Providing dependencies from outside instead of creating them inside a class.

### 85. Why use dependency injection?

**Answer:** It improves testability, flexibility, and separation of concerns.

### 86. What is linting?

**Answer:** Checking code for style and possibleerrors.

### 87. What is formatter?

**Answer:** A tool that automatically formats code consistently.

### 88. What is static typing?

**Answer:** Variable types are checked before runtime.

### 89. What is dynamic typing?

**Answer:** Variable types are checked during runtime.

### 90. What is compile-time error?

**Answer:** An error found before the program runs.

### 91. What is runtime error?

**Answer:** An error that happens while the program is running.

### 92. What is memory leak?

**Answer:** Memory that is no longer needed but notreleased.

### 93. What is concurrency?

**Answer:** Handling multiple tasks during overlapping time periods.

### 94. What is parallelism?

**Answer:** Running multiple tasks at the same time on multiple processors/cores.

### 95. What is async/await?

**Answer:** A syntax for writing non-blockingasynchronous code clearly.

### 96. What is containerization?

**Answer:** Packaging an app and dependencies into a container image.

### 97. What is CI/CD for modern apps?

**Answer:** Automated build, test, and deploymentpipelines.

### 98. How choose a framework for a project?

**Answer:** Consider team skill, ecosystem, performance, maintainability, security, and business requirements.

### 99. How explain your programming strength in interview?

**Answer:** I would say I can build APIs, integrate services, write clean code, test it, and deploy it reliably.

### 100. What is an important interview point for Modern Programming Languages &Frameworks?

**Answer:** Explain the concept simply, give a practical example, and mention trade-offs orlimitations.
