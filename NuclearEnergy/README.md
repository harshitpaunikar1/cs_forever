# Nuclear Energy Study Guide

This folder is a self-contained nuclear energy curriculum organized in the same app-friendly pattern as `Computer_Science`, but focused on how real plants run, which engineering tools matter, and how to build a text-first learning path in 2026.

The center of gravity is practical plant understanding. A modern nuclear plant is a reactor core plus thermal systems, chemistry, electrical systems, industrial automation, maintenance discipline, radiation protection, and safety-critical decision making. The goal of this guide is to connect those layers to projects, jobs, certifications, and an India-specific route.

## How to Use This Guide

1. Start with `Foundation` if you need the big-picture model of how a plant works, why reactor control is different from ordinary industrial control, and which software stack matters.
2. Move through `Core Nuclear` in order. That section is the real operating-plant layer: core behavior, heat removal, steam cycle systems, I&C, trips, chemistry, radiation, and grid integration.
3. Use `Advanced` to specialize into simulation, digital twins, historian data, predictive maintenance, OT cybersecurity, and India-sector strategy.
4. Use `Projects` as the proof layer. The target is not passive understanding. The target is inspectable engineering artifacts.
5. Use `Resources` for text-based references, official source links, and curated indexes.

## Section Map

- `Foundation`: curriculum overview, roadmap, plant basics, reactor fundamentals, tooling, control basics, and nuclear safety culture.
- `Core Nuclear`: reactor engineering, thermal hydraulics, steam systems, maintenance-critical equipment, plant I&C, control-room logic, chemistry, radiation, and electrical systems.
- `Advanced`: simulation tools, digital twins, industrial data architecture, predictive maintenance, OT cyber, India pathways, and advanced-reactor direction.
- `Projects`: beginner, intermediate, and advanced portfolio paths aligned to industrial nuclear and automation work.
- `Resources`: official-source indexes for text-based study.
