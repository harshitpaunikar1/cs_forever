# Contributing

This `NuclearEnergy` section is a self-contained local curriculum package.

## Local Editing Rules

1. Keep runtime content inside `NuclearEnergy`.
2. Preserve the app flow: `nav.json` drives navigation and markdown files are loaded directly.
3. Prefer official or primary-source links for standards, vendor docs, regulator pages, and course references.
4. Keep the curriculum practical, plant-oriented, and text-first.

## Useful Improvements

- Fix broken local links.
- Expand topic pages where plant behavior, controls, or India pathways need more depth.
- Add new resource links only if they are durable and clearly relevant.
