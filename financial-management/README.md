# Financial Management

A structured guide to financial management — from foundational concepts through
capital markets, corporate finance decisions, and advanced topics. Each topic covers
the core concept, key terms, real use cases, and worked examples, followed by 209
practice questions graded Basic → Intermediate → Advanced.

---

## Core Topics

| Topic | What You Will Learn |
|-------|---------------------|
| FM Foundations | Goals of finance, planning, working capital, cash, receivables |
| Valuation & Risk Basics | Time value of money, capital budgeting, risk, market efficiency, derivatives |
| Financial Environment | FM environment, financial statements, ratio analysis, TVM deep-dive |
| Markets, Valuation & Options | Bonds, CAPM, corporate valuation, financial options |
| Capital Decisions & Planning | WACC, capital budgeting, cash flow estimation, corporate governance |
| Corporate Finance | Dividends, capital structure, working capital, multinational finance |
| Advanced Financing | Lease, hybrid securities, APV, mergers, ERM, bankruptcy |
| Special Topics | Portfolio theory, real options, credit, cash management, pensions, not-for-profits |
