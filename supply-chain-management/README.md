# Supply Chain Management

A structured guide to supply chain management — from foundational concepts and
inventory principles through network design, transportation, and uncertainty planning.
Each topic covers the core concept, key terms, real use cases, and worked examples,
followed by 210 practice questions graded Basic → Intermediate → Advanced.

---

## Core Topics

| Topic | What You Will Learn |
|-------|---------------------|
| Introduction to SCM | How materials, information, and money flow from supplier to customer |
| Beer Game Simulation | Why small demand changes cause large order swings up the chain |
| Information Flow | Sharing accurate, timely data across supply chain partners |
| Bullwhip Effect | How demand gets distorted and amplified upstream |
| Demand Forecasting | Predicting customer demand to plan production and inventory |
| Short-Life-Cycle Inventory | Managing stock for seasonal and trend-driven products |
| Long-Horizon Inventory | Reorder points, safety stock, and holding cost trade-offs |
| Multi-Echelon Inventory | Coordinating stock across factory, warehouse, and store levels |
| Distribution Planning | Routing products from warehouse to customer efficiently |
| Network Planning | Choosing where to place facilities for cost and speed |
| Transportation Networks | Mode selection, routing, and freight consolidation |
| Planning Under Uncertainty | Building flexibility and buffers for disruption resilience |
