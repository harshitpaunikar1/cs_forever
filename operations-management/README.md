# Operations Management

A structured guide to operations management — from foundational concepts and
process design through inventory control, queueing theory, and modern digital
operations. Each topic covers the core concept, key terms, real use cases, and
worked examples, followed by 210 practice questions graded Basic → Intermediate → Advanced.
