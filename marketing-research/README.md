# Marketing Research

A structured guide to marketing research fundamentals — from problem definition
through data collection, analysis, and application. Each topic covers the core
concept, key terms, real use cases, and worked examples, followed by 210 practice
questions graded Basic → Intermediate → Advanced.

---

## Core Topics

| Topic | What You Will Learn |
|-------|---------------------|
| Research Environment | How research fits into business decision-making |
| Problem Formulation | Turning vague concerns into precise research questions |
| Research Design | Exploratory, descriptive, and causal approaches |
| Qualitative Research | Focus groups, interviews, and observation methods |
| Measurement Scales | Nominal, ordinal, interval, and ratio scales |
| Questionnaire Design | Writing clear, unbiased, effective survey questions |
| Sampling Procedures | Choosing representative samples efficiently |
| Fieldwork & Data Collection | Running surveys and maintaining data quality |
| Data Preparation | Cleaning, coding, and organising raw data |
| Statistics & Tests | Descriptive stats, t-tests, and chi-square tests |
